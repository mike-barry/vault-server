# Questions

The escalation channel between this build and whoever holds the missing context. Its normal state is empty.

A question reaches this file only after the operator has agreed it should. Raise the gap in session first and say what is blocked; only an agreed escalation is written here. This is not a place to park anything uncertain and move on.

Entry shape:

```
## <The question>

Asked: date, and what was being built at the time.
Blocked: what stopped, and what can continue meanwhile.
What the bundle says, and why it does not settle this.
What the build would do under each plausible reading, and what it costs to be wrong.

Answer: filled in by the responder, naming the spec file amended.
```

Clear the entry once its answer has been read, the specs amended, and the code updated to match. The amended spec is the requirement; the answer here is a receipt. The exchange stays in git history.
